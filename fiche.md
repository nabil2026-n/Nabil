# Définition des 15 termes du Web

## Internet

Internet est un grand réseau qui connecte des ordinateurs dans le monde
entier par contre ce n'est pas le web car le web c'est une partie
d'internet et internet ce n'est pas une partie du web.

## Web

le world wide web (www) a été inventé en 1989 et il est composé de sites
de plus il est lié à internet mais ce n'est pas internte car il
fonctionne grâce à Internet, Il permet d'accéder à des pages web avec un
navigateur comme Chrome.

## client

c'est un logiciel qui demande des informations à un serveur comme le
navigateur(chrome, edge , etc) cela, c'est le client et c'est le
logiciel qui demande des informations des sites d'internet.

## serveur

Serveur est un logiciel offrant un service que le client demande. Par
exemple, un serveur web peut envoyer des pages web au client.

## navigateur

c'est un logiciel qui permet d'accéder aux sites et aux pages web sur
Internet. Par exemple, Chrome, Edge et Firefox sont des navigateurs.

## nom de domaine

c'est le nom de site et on l'utilise comme l'adresse pour trouver le
site qu'on le veut par exemple : google.com

## hébergement

c'est une servece et place pour stocké le site et pour après les clients
sont capable à trouver et entrer sur le site

## DNS

en général, il est comme le traducteur entre le nom de demaine et le
systeme d'ordinateur. il transform le nom an un numéro (adresse ip)

## URL

c'est un adresse pour trouver un site par contre quand on l'utilise , on
connais quel site et quelle page on veut parce que ce adresse sera
unique sur le web

## HTTP

(hypertext transfer protocol) c'est le lien entre le serveur et le
client et il fait comme le protocol de communication entre les deux

## HTTPS

c'est comme (HTTP) mais ce version il est sécurisée et protége les
information entre le client et le serveur car il utilise (TLS)

## requête

c'est une manièr pour demand un service de serveur et le client qui
envoie la demande par exemple pour ouvrir un site

## réponse

c'est le réponse qui sera après le requête et le serveur qui l'envoie et
ça peut être succès ou pas

## code de statut

c'est le statut de réponse (2xx) qui dit le réponse est succès (3xx) les
messages de redirection (4xx) les erreurs du client (5xx) les erreurs du
serveur

## API

c'est qui permet contact avec deux logiciales et d'échanger des
informations.
